#+title: emacs.v86.js

Emacs in your browser at [[https://play.emacsen.de/]].

Originally on [[https://github.com/copy/v86][copy/v86]],
migrated to [[https://github.com/pithings/unkernel][unkernel]] for performance.

* What is it for?

... [[https://justforfunnoreally.dev/][fun]]?
(And I also might want to use it for interactive Lisp execution
on [[https://doc.emacsen.de][doc.emacsen.de]].)

* How's the performance?

Try it yourself: it's slow but not too slow now.

* Build

- Run =make= to generate all the needed files (unkernel root file system & home directory mounts).

- Run =pnpm install= and then =pnpm build= to generate the site.
